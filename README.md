# Awesome Forward Deployed Engineering [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated list of the best writing, talks, hiring pages, and interview material on Forward Deployed Engineering (FDE).

A Forward Deployed Engineer is a software engineer who works directly inside a customer's environment to build, integrate, and ship production systems, then feeds what they learn back into the core product. Palantir created the role. AI labs and enterprise software companies now hire for it widely.

This list favors primary sources: what the companies that run FDE teams say about the role, talks by the people who lead those teams, and official hiring guidance. Every entry is FDE-specific or directly useful for FDE work. General AI engineering material is limited to a short, practical section. Paid courses and coaching are not listed.

Maintained by [FDE Dispatch](https://fdedispatch.com). Links last checked October 2026. Suggestions are welcome: see [Contributing](#contributing).

## Skills to build

- [How to become a Forward Deployed Engineer (FDE Dispatch)](https://fdedispatch.com/how-to-become-a-forward-deployed-engineer/) - A three-phase, 90-day path from software engineer or data scientist to FDE.
- [Building effective agents (Anthropic)](https://www.anthropic.com/engineering/building-effective-agents) - Patterns for agent systems that hold up in production.
- [A practical guide to building agents (OpenAI)](https://cdn.openai.com/business-guides-and-resources/a-practical-guide-to-building-agents.pdf) - OpenAI's guide to agent design, tools, and guardrails, aimed at deployment teams.
- [Demystifying evals for AI agents (Anthropic)](https://www.anthropic.com/engineering/demystifying-evals-for-ai-agents) - How to measure whether an agent works, the core of eval-driven delivery.
- [LLM Evals FAQ (Hamel Husain)](https://hamel.dev/blog/posts/evals-faq/) - Practical answers on building evals for real applications.
- [Patterns for building LLM-based systems and products (Eugene Yan)](https://eugeneyan.com/writing/llm-patterns/) - Evals, retrieval, guardrails, and feedback patterns in one reference.
- [12-Factor Agents](https://github.com/humanlayer/12-factor-agents) - Engineering principles for reliable agents in customer systems.
- [Model Context Protocol](https://modelcontextprotocol.io/) - The open standard for connecting models to tools and data; Anthropic's FDE postings list MCP servers as deliverables.
- [Select Star SQL](https://selectstarsql.com/) - Free interactive SQL book for the data work most deployments involve.
- [Enterprise Integration Patterns](https://www.enterpriseintegrationpatterns.com/) - The standard vocabulary for connecting systems that were not built to talk to each other.
- [The Mom Test](https://www.momtestbook.com/) - Short book on asking customers questions that get honest answers, useful for discovery.
